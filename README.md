# FocusFlow - Productivity & Focus App

A productivity app designed to help users stay focused, manage tasks, and track deep work sessions.

**Live Demo:https://focus-flow-mu-seven.vercel.app/
**Repo:** https://github.com/David01Afolayan/FocusFlow

## Problem It Solves
Helps users beat distractions and improve productivity with focus timers, task management, and progress tracking.

## Features
- Pomodoro Focus Timer
- Task Management & Prioritization
- Daily Progress Tracking
- Minimal, Distraction-Free UI
- Session History & Analytics
- Responsive Design

## Tech Stack
- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: Next.js API / Node.js
- Database: PostgreSQL
- Deployment: Vercel
